Starship Feasibility

  • Separator glyph U+E0B0 (▶) — standard Powerline arrow; requires a Nerd Font or Powerline-patched font. Starship uses format strings: place [](fg:PREV_COLOR bg:NEXT_COLOR) between each module to produce the transition chevron.
  • Apple icon U+F0035 — Nerd Font supplementary private-use codepoint. Use 󰀵 in HTML or the literal UTF-8 character in a Starship format string after confirming it renders in your terminal. Alternatively U+E711 or U+F179 are more widely supported Apple/macOS icons in older Nerd Font v2 installations.
  • Rainbow ribbon — implement as six consecutive empty-content Starship custom modules. Each sets when = "true", an empty command = "", a style = "bg:COLOR fg:COLOR", and an empty format string. The [](fg:PREV bg:NEXT) between them produces the chevron. In practice this adds ~6 ms to prompt rendering (one shell true per module) — acceptable.
  • No U+E0B4 / U+E0B6 — those glyphs are the rounded left/right caps; they are simply never used in this design. All segments start and end with the straight-edge U+E0B0 chevron or a sharp terminal edge.
  • No explicit inter-segment spacer text — zero-width or single-space padding in CSS / Starship format strings must not produce a visible gap between solid segments. All padding is absorbed into the segment itself.
  • Verified glyphs: clock U+F017 (), folder U+F07B (), git branch U+E0A0 (), Python U+F0320 (󰌠) — all Nerd Font icons within content spans only.
