rationale

UV black-light rave atmosphere. The near-black violet base (#0a0612) is warmer and more distinctive than the flat blacks used by vaporwave/cyber-tokyo. The chartreuse (#b5ff2b) used for the path chip is the defining hue — it evokes acid house fluorescents and is genuinely unique across all current themes. Fuchsia orchid (#d946ef) for the git branch has orchid's name directly, and sits far enough from vaporwave's hot-pink (#ff71ce) to read as a different emotion. Acid lime (#a3e635) for Python keeps the green family but at a higher chroma than any current lang colour. Separator: pixel-fade U+E0C6 doubled for a decay shimmer between segments — segments butt directly with no gap or cap.

  • No blue hues anywhere — total break from the blue-heavy current roster
  • Chip text is the base background itself, so the "dark text inside" contract holds
  • Amber dirty indicator avoids green family clash with lime lang chip
  • Double pixel separator reads as a dissolve edge, fitting the acid-rave aesthetic

rationale

Koi fish live in still dark water; under laser light their orange-red bodies glow against the black. The abyssal background (#04080f) is darker and bluer-tinged than even material-ocean, making chips appear to float. Koi orange (#ff6b35) for the path chip is warmer than any existing theme — a completely unoccupied hue band in the current roster. Bioluminescent teal (#00e5cc) for git is clearly distinct from vaporwave's cyan-blue (#01cdfe) because it leans green rather than blue. Hot magenta (#f72585) for Python is the most saturated deep-pink available without merging into vaporwave's hot-pink. Separator: three consecutive standard chevrons U+E0B0 — the triple run reads as a speed streak, like laser light slicing water.

  • Only theme using orange in the path role — immediately distinctive at a glance
  • Gold dirty indicator harmonises with the warm-orange family without clashing
  • Highest contrast theme on very dark backgrounds (abyssal base + saturated chips)
  • Triple chevron creates directional momentum, reinforcing the "laser" motion metaphor

rationale

The most maximalist candidate. Pure neon green (#39ff14) is the canonical radioactive / UV-reactor colour — it appears nowhere else in the theme set. Candy pink (#ff3cac) for git has higher chroma and cooler undertone than vaporwave's hot-pink or cyber-tokyo's neon-red, keeping it meaningfully distinct. Electric yellow (#ffea00) for Python is the only theme using yellow in a chip role — zero risk of confusion. The neutral pure-black base (#0e0e0e) provides maximum contrast for all three saturated chip colours, and avoids the coloured-tinge bases used by the other two concepts here. Separator: single Lego/block glyph U+E0CE — the chunky block snap reads like candy snapping apart, and its visual weight holds the maximalist palette together.

  • Only theme with neon green — the single most unambiguous radioactive signal
  • Electric yellow lang chip reads differently from green path chip at a glance
  • Nuclear orange dirty indicator ties the "hazardous" metaphor together
  • Single lego block: deliberately bold, cuts through the loud colour without overcomplicating
  • Risk: the most aggressive of the three; may polarise — recommend offering as an opt-in
